# Bundled fonts

The frontend bundles unmodified font files from the pinned Fontsource packages below. Font loading uses local build assets; the running app makes no font-service request.

All three use the SIL Open Font License 1.1. Full notices are copied from their installed packages and included in the production build under `/fonts/`. These notices apply to the third-party fonts and do not license this project's own code.
